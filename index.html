实时语音与手机横屏

V7.3

手机画面适配

重排手机竖屏的牌桌、玩家头像、操作按钮和手牌；为手机横屏增加独立布局，减少遮挡。

V7.2

刷新恢复与断线重连

保存房间及玩家凭证，刷新后尝试恢复原座位与手牌；增加手动重连入口，并减少断线时的弹窗干扰。

V7.1

浏览器部署包

整理适合 GitHub 上传的网页、Worker、Durable Objects 配置与部署说明，支持通过 Cloudflare 网页自动部署。

V7.0

真人联网版

移除 AI 玩家，支持 4–6 人创建房间、输入六位房间号加入；游戏规则与私人手牌由服务器管理，同步出牌、质疑和胜负。
